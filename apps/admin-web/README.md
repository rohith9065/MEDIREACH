# admin-web

**Phase 9** — Super Admin console: hospital verification, user management, audit logs.

Vite + React + TypeScript + Tailwind CSS, hand-built components (no shadcn/ui — matches the
rest of this project's convention). Design direction: **"Console"** — cool graphite/slate
neutrals, one indigo accent, monospace-forward for identifiers and data tables. Deliberately
distinct from hospital-web's "Editorial" and patient-mobile's "Vivid & Energetic" so all three
frontends read as their own surface, while sharing the same hand-built-component philosophy.

Runs on port 5174 (`npm run dev --workspace=apps/admin-web`). Demo account:
`superadmin@demo.medireach.dev` / `Passw0rd!`.
